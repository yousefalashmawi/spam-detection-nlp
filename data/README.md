# Data

The datasets are downloaded automatically on first run (`src/data.py`):

| File | Source | Licence / citation |
|---|---|---|
| `sms.tsv` | SMS Spam Collection, UCI ML Repository (Almeida & Hidalgo, 2011) | CC BY 4.0 |
| `enron_spam_data.csv` | Enron-Spam (Metsis, Androutsopoulos & Paliouras, 2006), CSV by M. Wiechmann (github.com/MWiechmann/enron_spam_data) | public research corpus |

They are not committed to the repository (see `.gitignore`).
